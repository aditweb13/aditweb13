  1. 65.7%lower cost than Super-only, 40-ticket dev set

    Cascade: a cost-aware model router for AI agents

    Requests start on NVIDIA Nemotron Nano and move up to Super and then Ultra only when a verifier rejects the answer. The verifier checks schema, tool grounding, policy rules, self-consistency and an LLM judge. Every call logs tokens, cost and latency to SQLite for a Streamlit dashboard and evaluation harness.

    On the dev set it reached 90.0% accuracy.

    Held-out result: on a 50-ticket frozen set, Cascade scored 42.0% accuracy against 56.0% for single-tier baselines, at about 73% lower cost than Super-only. The router saves money, but it loses accuracy on unseen tickets.
